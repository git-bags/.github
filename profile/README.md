# Futarchy-Gated Funding Pools

### Open-source infrastructure funding on Avalanche, powered by prediction markets

</div>

---

Futarchy-based grant funding primitive for OSS infrastructure projects. Uses conditional markets (YES/NO vaults), TWAP-confirmed usage-based unlock tranches, and a spend-cap structure to fund what the market believes will actually be used — while correcting for the self-fulfilling-prophecy problem.

**Key features:**
- Prediction markets replace committee votes and popularity contests
- Usage-based KPIs (not token price) gate funding unlocks
- Default allowances keep projects alive independent of market sentiment
- Standing kill-switch lets contributors reclaim funds from underperforming projects

Built on proven MetaDAO/Futard.io mechanics, adapted for Avalanche subnets.
